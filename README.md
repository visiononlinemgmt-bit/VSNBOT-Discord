# Discord Mod Bot (Advanced Moderation System)

Комплексное решение для модерации и управления сообществом в Discord. Бот сочетает в себе классические инструменты модерации, современный AI-функционал, умную систему верификации форумных апелляций и локальную базу данных для обхода лимитов API.

---

## 🚀 Основные возможности

### ⚖️ 1. Система Наказаний (Slash Commands)
Упрощенная и стандартизированная выдача санкций. 
- `/chsp`, `/chs`, `/btd` — Основные роли наказаний.
- `/forgive` — Снятие всех наказаний.
- `/punishments` — **NEW**: Список всех наказанных (использует локальную БД для скорости).
- `/unmute` — Снятие тайм-аута.
- `/warns` / `/clear-warns` — Управление счетчиком нарушений.

### 🤖 2. Интеллектуальный AI-Консультант (`/ask`)
- **Модель**: OpenRouter (Trinity Large).
- **Контекст**: Динамически считывает правила из каналов при запуске.

### 📝 3. Валидация Апелляций (Fuzzy Matching)
- Автоматическая проверка формата апелляций в форумных каналах с точностью до 65%.

### 🔇 4. Авто-модерация Чат-фильтра
- Накопительная система мутов (от 5 мин до 28 дней).
- `/words` (list/add/remove) — **NEW**: Динамическое управление банвордами без перезагрузки.

### 📦 5. База Данных Наказаний (Persistence)
Для решения проблемы с лимитами (**GatewayRateLimitError**):
- **`punishments.json`**: Хранит статус наказанных локально.
- **Sync on Startup**: Бот синхронизируется с Discord один раз при запуске, что позволяет `/punishments` отвечать мгновенно.

## 🛠 Установка и запуск

1. `npm install`
2. Настройте `.env` (Токен, Client ID, OpenRouter Key)
3. `node src/register-commands.js` (Регистрация слэш-команд)
4. `npm start`

## 🛡 Система Кодирования Ошибок (Error Obfuscation)

Если команда выдает ошибку, пользователь увидит только Hex-код. Это защищает технические данные сервера.

| Код | Описание | Причина |
| :--- | :--- | :--- |
| **`0x1`** | Rate Limit | Бот превысил лимит запросов в Discord. |
| **`0x2`** | Missing Permissions | Роль бота ниже цели или не хватает прав. |
| **`0x3`** | Unknown Member | Пользователь покинул сервер. |
| **`0x4`** | Missing Access | У бота нет доступа к каналу или ресурсу. |
| **`0x5`** | Unknown Message | Сообщение было удалено до обработки. |
| **`0x6`** | Guild Limits | Достигнут лимит на сервере (например, ролей). |
| **`0x7`** | Unauthorized | Ошибка авторизации (проблема с токеном). |
| **`0x8`** | Invalid Recipient | Не удалось отправить сообщение (например, в ЛС). |
| **`0x9`** | Invalid Form Body | Ошибка в опциях или формате команды. |
| **`0x10`** | AI Error | Проблема с AI-сервисом (OpenRouter). |
| **`0x11`** | Config Error | Ошибка в файле настроек `config.json`. |
| **`0x0`** | Unknown Error | Непредвиденная системная ошибка. |

---

## ⚙️ Настройка (`config.json`)

- `forbiddenWords`: Список запрещенных слов.
- `accessControl`: Каналы и роли, имеющие доступ к модерации.
- `targetRoles`: ID ролей для ЧСП, ЧС и БТД.
- `violationForgivenessDays`: Через сколько дней сбрасываются варны (по умолчанию 30).
