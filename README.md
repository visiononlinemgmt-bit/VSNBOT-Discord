# Discord Mod Bot (Advanced Moderation System)

Комплексное решение для модерации и управления сообществом в Discord. Бот сочетает в себе классические инструменты модерации, современный AI-функционал и умную систему верификации форумных апелляций.

---

## 🚀 Основные возможности

### 🤖 1. Интеллектуальный AI-Консультант (`/ask`)
Позволяет персоналу или доверенным лицам получать мгновенные консультации по правилам проекта.
- **Модель**: `arcee-ai/trinity-large-preview:free` (через OpenRouter).
- **Обучение**: Бот динамически считывает последние сообщения из каналов правил (`Rules` и `Admin Rules`) при запуске, формируя актуальную базу знаний.
- **Фильтрация**: AI обучен игнорировать вопросы, не касающиеся проекта (погода, математика, общие вопросы), вежливо отказывая в ответе.
- **Особенности**: Поддержка форматирования Discord в ответах.

### ⚖️ 2. Система Глобальных Наказаний (Slash Commands)
Упрощенная и стандартизированная выдача тяжелых наказаний.
- `/chsp` — **Черный Список Проекта**. Полная изоляция пользователя.
- `/chs` — **Черный Список**. Ограничение доступа к серверу.
- `/btd` — **Бессрочная Терминация Доступа**. Максимальный уровень блокировки.
- `/forgive` — **Прощение**. Снятие всех вышеуказанных ролей.
- **Логика работы**:
  - При выполнении команды бот **автоматически снимает все текущие роли** пользователя (кроме системных), чтобы избежать конфликтов доступов.
  - Строгая проверка **иерархии ролей**: модератор не может наказать пользователя с ролью выше или равной его собственной.
  - Каждое действие сопровождается подробным Embed-сообщением в чате и логом.

### 📝 3. Умная Валидация Апелляций (Fuzzy Matching)
Автоматизирует первичную проверку апелляций в форумных каналах.
- **Технология**: Использование алгоритма нечеткого поиска (Fuzzy Matching) для сравнения сообщений с шаблонами.
- **Порог**: Требуется совпадение минимум **65%** ключевых фраз из соответствующего шаблона (Бан, ЧС или БТД).
- **Интерактивность**:
  - При создании темы бот мгновенно пишет сообщение "Проверка формата".
  - После анализа сообщение редактируется либо на поздравление с успешной верификацией, либо на предупреждение о несоответствии.

### 🔇 4. Авто-модерация Чат-фильтра
Защита чата от запрещенного контента в реальном времени.
- **Накопительная система**: Срок мута увеличивается при каждом повторном нарушении:
  1. 5 минут
  2. 10 минут
  3. 30 минут
  4. 1 час
  5. 24 часа
  6. 1 неделя
  7. 28 дней (максимум Discord API)
- **Прощение**: Старые нарушения автоматически забываются через 30 дней покоя.
- **Нормализация**: Бот распознает слова даже при использовании разного регистра или диакритических знаков.

### 📢 5. Система Уведомления о Правилах
Автоматическое информирование участников об изменениях в регламенте.
- Мониторинг редактирования существующих правил.
- Мониторинг создания новых правил.
- Поддержка "Было / Стало" при редактировании для наглядности изменений.

## 🛠 Установка и запуск

### Требования
- Node.js версии 16.10 или выше.
- Аккаунт OpenRouter (для AI).
- Discord Приложение с включенными **Intents** (Message Content, Server Members).

### Шаги установки
1. **Зависимости**:
   ```bash
   npm install
   ```
2. **Переменные окружения**:
   Создайте файл `.env` в корневой папке:
   ```env
   DISCORD_BOT_TOKEN=ваш_токен
   DISCORD_CLIENT_ID=id_вашего_бота
   OPENROUTER_API_KEY=ваш_ключ_openrouter
   ```
3. **Регистрация команд**:
   Бот использует слэш-команды, которые нужно "объявить" Discord API:
   ```bash
   node src/register-commands.js
   ```
4. **Запуск**:
   ```bash
   npm start
   ```

## ⚙️ Глубокая настройка (`config.json`)

Файл конфигурации разбит на логические секции:

- `forbiddenWords`: Список слов, за которые выдается автоматический мут.
- `muteReportsChannelId`: Канал для отправки отчетов модераторам.
- `rulesChannels`: Массив объектов, определяющих каналы правил и роли для уведомлений.
- `forumAppealChannels`: Форумные каналы, где работает умная валидация.
- `accessControl`:
  - `allowedChannelId`: Единственный канал, где работают команды наказаний.
  - `targetRoles`: Маппинг команд на ID соответствующих ролей на сервере.
- `ai`:
  - `allowedRoleIds`: Кто может использовать `/ask`.
  - `contextChannels`: Откуда ИИ черпает знания о проекте.

## ❓ Troubleshooting (Решение проблем)

### Бот не реагирует на сообщения
Проверьте, включен ли **Message Content Intent** в Discord Developer Portal. Без этого флага Discord блокирует доступ бота к тексту сообщений.

### Ошибки подключения (Timeout)
Если бот не может подключиться к Discord, проект настроен на принудительное использование IPv4 через флаг `--dns-result-order=ipv4first` в `package.json`. Это решает проблему на большинстве современных серверов.

### AI выдает 429 ошибку
Это означает превышение лимитов (Quota/Rate Limit) бесплатного тира OpenRouter или модели. Мы оптимизировали контекст (берем только последние 20 сообщений), чтобы минимизировать затраты токенов.

### Команды не появились в Discord
Регистрация команд в `register-commands.js` настроена как **локальная** (applicationGuildCommands). Убедитесь, что в коде указан правильный `GUILD_ID` вашего сервера.
